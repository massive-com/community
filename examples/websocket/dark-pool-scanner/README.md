# Dark Pool Scanner

  <img src="../../../images/logo_new.png" alt="Project Logo" width="100%"/>
</div>

A Python utility that streams real-time US stock trades and filters them to show only dark pool activity using Massive's WebSocket API. Dark pool trades are executed off-exchange and reported through FINRA Trade Reporting Facilities (TRFs). This scanner identifies those trades in real time and displays them with readable timestamps, venue details, and notional value.

## Features

- **Real-time streaming**: Connects to Massive's stock trades WebSocket for live data
- **Dark pool filtering**: Identifies off-exchange trades using the exchange ID and TRF identifier fields
- **Notional threshold**: Filters for significant block trades above a configurable dollar amount
- **Ticker filtering**: Watch all tickers or narrow to specific symbols
- **TRF venue mapping**: Maps TRF IDs to human-readable venue names (NYSE TRF, NASDAQ TRF Carteret, NASDAQ TRF Chicago)
- **Eastern time display**: Converts millisecond epoch timestamps to readable Eastern time strings

## What's inside

This tool provides a fast "tape" view of live dark pool prints:

- **WebSocket connection**: Subscribes to stock trades via `T.*` (all tickers) or specific ticker streams
- **Dark pool detection**: Filters for `exchange == 4` (TRF) with a valid `trf_id`
- **Notional calculation**: Computes total dollar value as `price * size`
- **Timezone handling**: Uses Python's built-in `zoneinfo` for US/Eastern formatting

## Quickstart

1. **Clone the repository**:
   ```bash
   git clone https://github.com/massive-com/community.git
   cd community/examples/websocket/dark-pool-scanner
   ```

2. **Install dependencies with uv**:
   ```bash
   uv sync
   ```

3. **Set up your API key**:
   ```bash
   cp .env.example .env
   # Edit .env and add your MASSIVE_API_KEY
   ```

4. **Get a Massive API key**:
   - Visit [massive.com](https://massive.com/)
   - Sign up for an account
   - Upgrade to Stocks Advanced
   - Copy your API key

## Usage

### Run the scanner

```bash
uv run main.py
```

By default the scanner shows only TRF trades with notional >= $100,000. You can adjust the threshold or filter to specific tickers:

```bash
# Lower the notional threshold to $50,000
uv run main.py --min-notional 50000

# Watch only NVDA and TSLA dark pool prints
uv run main.py --ticker NVDA TSLA

# Combine both
uv run main.py --ticker AAPL --min-notional 200000
```

Stop the stream anytime with `Ctrl+C`.

## How it works

### Dark pool detection

Dark pool trades are reported through FINRA Trade Reporting Facilities (TRFs). The scanner identifies them by checking two fields on each incoming trade message:

- `exchange == 4`: The trade was reported to a TRF, meaning it executed off-exchange
- `trf_id` is present: Identifies which specific TRF processed the trade

Only trades that satisfy both conditions are displayed.

### TRF venue mapping

There are three FINRA Trade Reporting Facilities:

| TRF ID | Venue Name |
|--------|------------|
| 201 | FINRA/NYSE TRF |
| 202 | FINRA/NASDAQ TRF Carteret |
| 203 | FINRA/NASDAQ TRF Chicago |

### Notional calculation

Notional represents the total dollar value of the trade:

```
notional = price * size
```

Price per share multiplied by the number of shares. The default threshold of $100,000 focuses the output on institutional-sized prints and filters out the noise of smaller retail-sized fills.

### Timezone conversion

Trades arrive with millisecond epoch timestamps and are converted to readable Eastern time strings using Python's `zoneinfo` module. Eastern time matches US equity market hours, so timestamps align with the trading session.

## Troubleshooting

### Common issues

- **Not seeing any trades**
  - Confirm your plan includes real-time stock trades (Stocks Advanced)
  - Make sure the US stock market is open (9:30 AM to 4:00 PM ET for the regular session)
  - Double-check that your API key is correct

- **Authentication or subscription errors**
  - Re-check the API key and plan first
  - Ensure your `.env` file exists and contains `MASSIVE_API_KEY`
  - Ensure your Massive SDK version is up to date:
    ```bash
    uv sync --upgrade
    ```
