# Dark Pool Scanner

  <img src="../../../images/logo_new.png" alt="Project Logo" width="100%"/>

A Python utility that streams real-time US stock trades and filters them to show only dark pool activity using Massive's WebSocket API. This tool helps identify off-exchange trades by filtering for FINRA Trade Reporting Facility (TRF) transactions and displaying trades with readable timestamps and venue details.

## Features

- **Real-time Streaming**: Connects to Massive Stocks Trades WebSocket for live data
- **Dark Pool Filtering**: Identifies off-exchange trades using exchange ID and TRF identifier
- **Notional Filtering**: Filters for significant block trades above a configurable threshold
- **TRF Venue Mapping**: Maps TRF IDs to human-readable venue names (NYSE TRF, NASDAQ TRF Carteret, NASDAQ TRF Chicago)
- **Eastern Time Display**: Converts millisecond epoch timestamps to readable Eastern time strings
- **Clean Terminal Output**: Displays trade summaries with symbol, price, size, notional, venue, and timestamp

## What's Inside

This tool provides a fast "tape" view of live dark pool prints:

- **WebSocket Connection**: Subscribes to all stock trades via `T.*` stream
- **Dark Pool Detection**: Filters for `exchange == 4` (TRF) with a valid `trf_id`
- **Notional Calculation**: Computes total dollar value as `price × size`
- **Timezone Handling**: Uses Python's built-in `zoneinfo` for US/Eastern formatting

## Usage

### Run the Scanner

```bash
uv run main.py
```

The scanner shows only trades with notional ≥ $100,000. To change the threshold, edit the `MIN_NOTIONAL` value in `main.py`.

Stop the stream anytime with `Ctrl+C`.

## How It Works

### Dark Pool Detection

Dark pool trades are reported through FINRA Trade Reporting Facilities (TRFs). The script identifies them by checking two fields:
- **exchange == 4**: Indicates the trade was reported to a TRF (off-exchange)
- **trf_id is present**: Identifies which specific TRF processed the trade

### TRF Venue Mapping

There are three FINRA Trade Reporting Facilities:

| TRF ID | Venue Name |
|--------|------------|
| 201 | FINRA/NYSE TRF |
| 202 | FINRA/NASDAQ TRF Carteret |
| 203 | FINRA/NASDAQ TRF Chicago |

### Notional Calculation

Notional represents the total dollar value of the trade:
```
notional = price × size
```
Price per share multiplied by number of shares.

### Timezone Conversion

Trades arrive with millisecond epoch timestamps and are converted to readable Eastern time strings using Python's `zoneinfo` module.

## Easy Upgrades

Once the basic scanner is working, try these enhancements:

| Enhancement | Description |
|-------------|-------------|
| Filter by ticker | Only watch specific symbols (e.g., NVDA, TSLA) by subscribing to `T.NVDA,T.TSLA` instead of `T.*` |
| Add size filter | Filter by minimum share size in addition to notional |
| Log trades | Write trades to CSV/JSON for later analysis |
| Add alerts | Sound or notification when a large block trade crosses your threshold |
| Track volume | Accumulate volume by symbol to spot unusual accumulation patterns |

## Troubleshooting

### Common Issues

- **Not seeing any trades**
  - Confirm your plan includes real-time stock trades (Stocks Advanced)
  - Make sure the US Stock market is open (9:30 AM - 4:00 PM ET for regular session)
  - Double-check that your API key is correct

- **Authentication or subscription errors**
  - Re-check the API key and plan first
  - Ensure your `.env` file exists and contains `MASSIVE_API_KEY`
  - Ensure your Massive SDK version is up to date:
    ```bash
    uv sync --upgrade
    ```
