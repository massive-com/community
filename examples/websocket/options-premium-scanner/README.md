# Options Premium Scanner

A Python utility that streams real-time US options trades and filters them by premium size using Massive's WebSocket API. This tool helps identify large options prints by computing premium (price × contracts × 100) and displaying trades with readable timestamps and parsed contract details.

## Features

- **Real-time Streaming**: Connects to Massive Options Trades WebSocket for live data
- **Premium Filtering**: Set a minimum premium threshold to focus on significant trades
- **OSI Symbol Parsing**: Automatically parses option symbols into readable format (underlying, strike, type)
- **Eastern Time Display**: Converts millisecond epoch timestamps to readable Eastern time strings
- **Clean Terminal Output**: Displays trade summaries with symbol, contract, price, size, premium, strike, and exchange

## What's Inside

This tool provides a fast "tape" view of live options prints:

- **WebSocket Connection**: Subscribes to all options trades via `T.*` stream
- **Premium Calculation**: Computes total dollar value as `price × contracts × 100`
- **Contract Parsing**: Extracts underlying root, option type (Call/Put), and strike from OSI symbols
- **Timezone Handling**: Uses Python's built-in `zoneinfo` for US/Eastern formatting

- Massive API key (**Must be on Options Advanced license type**)

## Quickstart

1. **Clone the repository**:
   ```bash
   git clone https://github.com/massive-com/community.git
   cd community/examples/websocket/options-premium-scanner
   ```

2. **Install dependencies with uv**:
   ```bash
   uv sync
   ```

3. **Set up your API key**:
   ```bash
   cp .env.example .env
   # Edit .env and add your MASSIVE_API_KEY
   ```

4. **Get a Massive API key**:
   - Visit [massive.com](https://massive.com/)
   - Sign up for an account
   - Upgrade to Options Advanced
   - Copy your API key

## Usage

### Run the Scanner

```bash
uv run main.py
```

By default the scanner shows only trades with premium ≥ $100,000. To use a different threshold, pass the amount after the command:

```bash
uv run main.py 10000
```

Stop the stream anytime with `Ctrl+C`.

## How It Works

### OSI Symbol Parsing

Options trades arrive with a full contract symbol (e.g., `O:SPY251219C00450000`). The script parses this into:
- **Root**: Underlying symbol (e.g., `SPY`)
- **Type**: Call or Put
- **Strike**: Price in dollars (OSI encodes strikes in thousandths, so `00450000` becomes `450.00`)

### Premium Calculation

Premium represents the total dollar value of the trade:
```
premium = price × contracts × 100
```
One standard equity option contract represents 100 shares.

### Timezone Conversion

Trades arrive with millisecond epoch timestamps and are converted to readable Eastern time strings using Python's `zoneinfo` module.

## Troubleshooting

### Common Issues

- **Not seeing any trades**
  - Confirm your plan includes real-time options trades (Options Advanced)
  - Make sure the US Options market is open
  - Double-check that your API key is correct

- **Authentication or subscription errors**
  - Re-check the API key and plan first
  - Ensure your `.env` file exists and contains `MASSIVE_API_KEY`
  - Ensure your Massive SDK version is up to date:
    ```bash
    uv sync --upgrade
    ```
