## Background

[client-go v3](https://github.com/massive-com/client-go) is Massive's official Go client for the REST API. It is auto-generated from the OpenAPI spec using [oapi-codegen](https://github.com/oapi-codegen/oapi-codegen), so every endpoint, parameter, and response type matches the API exactly.

This demo is a single Go file that makes two API calls: fetching daily aggregate bars and a live ticker snapshot. It covers the core patterns you need to start building with client-go v3: typed request parameters, built-in pagination, error handling, and optional request tracing.

## What's inside

The demo runs two API calls sequentially:

1. **Daily aggregates.** Fetches OHLCV bars for a configurable number of days and prints them in a formatted table. Demonstrates auto-generated parameter types, `rest.Ptr()` helpers, and the pagination iterator.
2. **Ticker snapshot.** Fetches the current price, day change, session range, and volume. Demonstrates a simpler request/response pattern with `CheckResponse` error handling.

## How it works

### Client options

The client is created with `rest.NewWithOptions`, which accepts functional options:

```go
c := rest.NewWithOptions(apiKey,
    rest.WithTrace(true),       // log every HTTP request and response
    rest.WithPagination(true),  // automatically follow next_url links
)
```

`WithTrace` is useful for debugging. It prints the full request URL, headers, and response body for every API call. `WithPagination` enables the client to automatically follow paginated responses when used with the iterator.

### Auto-generated types

Every API endpoint has a corresponding params struct and method generated from the OpenAPI spec. Path parameters like ticker, timespan, from, and to are method arguments. Query parameters go in the params struct:

```go
params := gen.GetStocksAggregatesParams{
    Adjusted: rest.Ptr(true),
    Sort:     "asc",
    Limit:    rest.Ptr(50000),
}

resp, err := c.GetStocksAggregatesWithResponse(
    context.Background(),
    "AAPL",              // ticker (path param)
    1,                   // multiplier (path param)
    gen.Day,             // timespan (path param, typed enum)
    "2026-02-26",        // from (path param)
    "2026-03-03",        // to (path param)
    &params,
)
```

Optional fields are pointers. The `rest.Ptr()` helper creates a pointer to a literal value, which avoids the boilerplate of declaring a variable just to take its address.

### Pagination

The client includes a built-in pagination iterator. After making the initial request, wrap the response in `rest.NewIteratorFromResponse` and loop with `Next()`:

```go
iter := rest.NewIteratorFromResponse(c, resp)

for iter.Next() {
    item := iter.Item() // map[string]any
    // process item
}
if iter.Err() != nil {
    // handle error
}
```

The iterator automatically follows `next_url` links in the response until all pages are consumed. Each call to `Item()` returns a single result from the current page as a `map[string]any`.

### Error handling

Use `rest.CheckResponse` to turn non-200 responses into Go errors:

```go
resp, err := c.GetStocksSnapshotTickerWithResponse(context.Background(), ticker)
if err != nil {
    // network-level error
}
if err := rest.CheckResponse(resp); err != nil {
    // API returned an error status (401, 404, 429, etc.)
}
```

This pattern separates transport errors (DNS failures, timeouts) from API errors (bad request, rate limited, not found). Snapshot responses have strongly typed fields (`resp.JSON200.Ticker.Day.C`, `resp.JSON200.Ticker.TodaysChange`, etc.) generated directly from the OpenAPI spec.

## Troubleshooting

- **"MASSIVE_API_KEY environment variable is not set"**
  - Run `export MASSIVE_API_KEY=your-api-key` before `go run main.go`.
  - The demo reads the key from the environment directly. It does not use a `.env` file loader.

- **"API error" or 401 response**
  - Verify your API key is correct. Copy it fresh from the [Massive dashboard](https://massive.com/dashboard).
  - Check that your plan includes stock market data access.

- **No aggregate bars returned**
  - Make sure the date range includes business days. Weekends and holidays have no trading data.
  - Try increasing `--days` to cover a wider range.

- **Snapshot shows zero values**
  - Snapshots reflect the current or most recent trading session. Outside market hours (9:30 AM to 4:00 PM ET, weekdays), some fields may show the previous close.

- **Module download errors**
  - Run `go mod tidy` to resolve and download dependencies.
  - Make sure you have Go 1.21 or later: `go version`.
